# Portal API (PAPI)

Die Portal API verbindet das Portal-Frontend mit dem Backend. Im PoC wird ein Veröffentlichungsauftrag dokumentiert.

## Konkrete Endpunkte

- `POST /portal/v1/publication-jobs`
- `GET /portal/v1/publication-jobs/{jobId}`
